# CRMW 池 Excel 导入需求说明

> 前端页面：`crmw_pool_excel_import.html`
> 后端前缀：`/api/v1/crmwPoolExcelImport`
> 公共模板下载：`/api/v1/commonFile/downloadTemplate`
> 角色定位：具备 CRMW 投资池 `excel_importable` 权限的用户，通过 Excel 批量发起 **CRMW 凭证 + 标的证券** 组合的调入/调出。

### 同券关联市场范围

同券关联市场与投资池投资市场共用 `MarketCode` 集合（`SSE/SZSE/NIB/BSE/COMPANY/OTC/HKEX/QDII/JWCW/UNKNOWN/OTHER`），不另设白名单。先按 Wind `EXCHMARKET` 筛选主代码和关联代码，再查询本地主档；范围外代码不参与关联展示、关联校验和关联出入库，缺少主档不阻断，范围内缺少主档或市场仍报错。不按代码后缀或 `S_INFO_EXCHMARKET` 推断；目标池勾选的市场仍是逐券入池限制，不用于裁剪同券集合。证券池、ABS、CRMW、批量、Excel 及临时转正复用同一查询。

## 标的债券一券多码调库

- CRMW 凭证本身为单一代码，不存在多市场扩批；仅将其绑定标的债券按 Wind `S_INFO_ISINCODE` 展开同券代码，排除自身、去重、不递归。临时代码不参与同券展开。
- `checkExcelAdjust` 在手工、联动、互斥项生成后追加 `itemTag=related` 的关联调整项。每个实际代码独立校验市场、凭证+标的组合在池状态、活动池组、冻结期和原调库规则；同池调入累计主项及已通过关联项的容量。主券与关联码原校验原因完整保留；Excel 业务失败转为提示后整组可提交，关联证券无法识别或 ABS 身份冲突仍阻断整组，其他独立调库组不受影响。
- 同一 ISIN 的债券按各市场实际代码读取状态、摘牌日及在池情况。调入和调出结果均保留主券及每个关联市场的独立记录。已退市（`D`）、摘牌日早于当天或调出时已不在目标池等可放行的业务失败，仅在对应证券行显示为「调整提示」，该行仍标记为可调整。
- 人工单笔调入由后端重新核对各目标池要提交的同券代码。普通批量按已校验的组提交。Excel 按校验快照提交实际勾选的市场代码，原校验中的到期和在途原因仍作为调整提示。
- 关联项保持同一个 `crmwScode/crmwStype`，`sourceSecurityCode` 为触发主组合键 `crmwScode|securityCode`，共用原主项的 `adjustGroupKey`、流程与 CRMW 批次号，仅手工项创建流程步骤；关联项的报告要求由同组手工项承担。
- 提交 `items[]` 新增 `securityCode/securityShortName/securityType`，记录、快照与最终落池使用实际标的身份。未传明细代码的旧单组合请求继续使用请求级主券代码。直通即时生效，人工审批仅最终 `20` 同批落池；出池精确匹配原凭证、实际标的和目标池，保留其他凭证的组合。
- 批量同批结果按凭证、标的、目标池和方向去重，手工主项优先。Excel 批次统一目标池和方向，同一凭证下已展开的同券标的复用前面一行的校验结果。导入明细标注并入的原始行，关联项按自身主档回填全称、市场和类型，主体选择沿用组内发起行。
- 活动流程通过同批任一组合定位，关联码审批中不能在相同池组重复申请。`queryCrmwAdjustLogList` 返回当前组合全部历史及同批关联项，不按请求批次或终态过滤；返回项增加 `securityCode/securityShortName`，申请校验表和审核/详情记录表展示实际标的代码与名称。
- 自动到期调出继续逐条扫描实际在池组合，不再二次按 ISIN 扩批；本次不调整定时任务规则，不迁移历史数据，不变更表结构。

## 1. 页面概览

单页工作台：上方双卡 + 下方 Tab（导入明细 / 调库校验结果）。布局与 [28 证券池 Excel 导入](28-security-pool-excel-import.md) 一致，字段按 CRMW 组合替换。

1. **导入参数**
   - **目标池**：启用叶子 CRMW 池（`pool_type=crmw`）；仅一个池时自动选中
   - **调整方向**：调入 / 调出
   - **调整原因**、**调整意见**（选填）
   - 无导入类型、无「首先清空目标池」、无「允许联动与互斥」
2. **下载模板并上传**
   - 一个下载按钮：**下载CRMW模板**
   - 拖拽上传 xls/xlsx（≤5MB）
3. **导入明细** Tab：行级校验状态、筛选、分页；操作：清空 / 校验
4. **调库校验结果** Tab：操作：重新校验 / 提交
5. **提交** → 弹出「选择调库流程」对话框（与证券池 Excel 导入 / CRMW 批量一致）

### 1.1 模板列

| 类型 | 模板编码 | 列 |
|------|----------|----|
| CRMW | `crmw_pool_import` | CRMW代码、证券代码 |

目标池由页面选择。担保人和权益人在上传后的导入明细中选择。

### 1.2 导入明细列

序号、CRMW代码、CRMW全称、证券代码、证券全称、担保人、权益人、自选权益人、担保人主体内评分、CRMW市场、证券类型、证券市场、校验、校验说明。

- 可提交的导入行如有调整提示，在「校验说明」中汇总来源行及其展开项的提示，校验状态仍为通过。摘要最长 500 字符，完整原因保留在「调库校验结果」。
- 仅 ABS 上传行初始化首个权益人，已确认或在途主体优先回显。仅 ABS 展示权益人和自选权益人。仅担保债展示担保人和担保人主体内评分。上传时为担保债行优先回显已保存且仍有效的担保人，否则默认选中首项。评分随选择更新。ABS 担保债的担保人选择独立保存，与权益人及自选权益人一起回显。ABS 担保债的导入明细在 `fld020` 保存担保人代码。
- 非 ABS 有候选时须选择担保人，无候选时可留空。ABS 至少选择关联权益人或全市场自选权益人中的一种，自选优先，清除自选后恢复关联权益人内评。
- 按导入行独立保存主体选择，翻页和刷新后继续回显。任一行改选后，本批回到待校验并清除旧的调库结果和流程选择。已提交批次仅可查看。
- 同一 ABS 搭配不同凭证时须使用相同的有效主体。同批主体冲突在展开后追加至调整说明，保留原校验原因，并将对应组的手工、联动、互斥和关联项全部标为不可调整。

### 1.3 调库校验结果列

序号、CRMW代码、CRMW全称、证券代码、证券全称、审批流程、调整说明、调整类型、调整方向、投资池名称、权益人/担保人名称、权益人/担保人代码、CRMW市场、证券类型、证券市场、校验结果。

投资池名称显示每条调整项的实际目标池。

主体名称和代码按来源导入行展示，ABS 自选权益人优先。联动、互斥和关联项沿用来源行主体，校验失败时展示该行已保存的选择，无选择时留空。

## 2. 临时表（通用导入）

复用 `sys_imp_tmp` / `sys_imp_tmp_detl`。

- `biz_type`：`crmw_pool_excel`
- 主表槽：`fld001` 调整方向 in/out；`fld002` 调整原因；`fld003` 调整意见；`fld004` 目标池 ID；`fld005` 目标池名称；`fld006` 池类型
- `option_json`：`{ targetPoolId, targetPoolName, poolType }`
- 明细槽：`fld001` CRMW代码 / `fld002` CRMW全称 / `fld003` CRMW市场 / `fld004` 证券代码 / `fld005` 证券全称 / `fld006` 证券类型 / `fld007` 证券市场 / `fld008` crmwStype / `fld009` 目标池 ID / `fld010` 池类型 / `fld011` 证券类型名称 / `fld012`～`fld015` 依次保存关联主体代码、名称和自选权益人代码、名称

## 3. 接口

| 接口 | 说明 |
|------|------|
| `POST crmwPoolExcelImport/queryPoolList` | 当前用户可 Excel 导入的启用叶子 CRMW 池 |
| `POST commonFile/downloadTemplate` | `{ templateCode: crmw_pool_import }` → Base64 xlsx |
| `POST crmwPoolExcelImport/uploadExcel` | multipart：`request` JSON + `file` + 可选 `originalFileNameListJson` |
| `POST .../queryTask` | 批次信息 + `checkItems` |
| `POST .../queryItemPage` | 明细分页（关键字匹配 CRMW 代码片段或证券代码前缀） |
| `POST .../editRatingCompany` | 按批次和明细 ID 保存关联主体、自选权益人并清除旧校验 |
| `POST .../checkImport` | 逐组合委托 `checkExcelAdjust` |
| `POST .../submitImport` | 必填 `checkItems`，按来源行提交勾选项及所选流程 |
| `POST .../cancelImport` | 逻辑删除批次 |

权限：启用叶子 CRMW 池 + `excel_importable`（管理员 userId=1 放行）。

提交时复核批次目标池，并检查各条已勾选项实际目标池的 `excel_importable` 权限，包括联动、互斥和关联项。任一池无权限时本批提交失败。

## 4. 校验与提交口径

Excel 层只做：模板/临时表、目标池解析、`excel_importable` 权限、主数据回填和评级主体选择。
**调库可行性与落库不再自写简化版**，委托：

| 动作 | 服务 |
|------|------|
| 校验 | `CrmwPoolAdjustService.checkExcelAdjust`（原规则执行后转为业务提示） |
| 提交 | `CrmwPoolAdjustService.submitAdjustLog`（整批共享附件上下文与 `BatchNoContext`） |

- 每行 Excel → 一凭证 + 一标的 + 一目标池 + 方向
- 上传和每次校验都按 Excel 行序检查「CRMW 凭证代码 + 标的证券代码 + 批次目标池」是否重复。代码去除首尾空格，忽略大小写。首行继续校验，后续重复行显示「不可调整」并禁选。重复行不参与 ABS 主体一致性检查。
- 保留完整展开项（手工 / 联动 / 互斥 / 关联），主项保留单笔候选并追加已配置的 batchIn/batchOut
- 校验结果「调整类型」：手工主项 **Excel导入**；联动/互斥/关联同名
- 调库校验结果把可调整项放在前面，不可调整项放在末尾，两类各自保留校验顺序。默认勾选全部可调整项，支持逐行勾选和表头全选，不可调整项禁选。全部可调整但有调整提示时，校验结束用警告消息提醒。
- 提交时按校验快照核对每个勾选项，拒绝空选、重复选择或未通过校验的项。按来源导入行分组，勾选的手工项采用所选流程。仅勾选配套项时，由首个已勾选项沿用来源主项的默认流程发起，日志记为 `Excel导入`。
- 确认弹窗按来源行列出单独勾选的配套项的凭证和标的代码，并只读显示这些项将沿用的默认流程。
- 提交前按来源导入行复核关联主体和自选权益人的资格。申请快照使用实际提交的标的证券和已复核的主体，所选审批流程须匹配本次校验返回的候选。
- 存在直通项时先 `recheckBeforeFinalApproval`
- 无「首先清空目标池」

## 当前市场口径

市场按当前代码在 `rrs_securityinfo.market` 的本地市场值校验（外部导入与 Wind `EXCHMARKET` 保持一致），银行间使用 NIB；临时代码使用登记表市场。关联券其他市场不使当前代码通过市场限制。批量候选直接按主档市场筛选，临时代码用登记表 EXISTS 筛选，展示按当前页批量查询唯一市场，避免关联连接重复分页或逐行市场查询。CRMW 导入复用证券主档缓存，同一代码的市场只查询一次。缺失、重复或不支持的映射报出具体代码。


## 批量流程与 Excel 提示放行

- 普通单笔继续使用原业务规则；普通批量追加已配置的批量流程，业务失败仍阻断
- Excel 通过 `checkExcelAdjust` 执行完整规则，再将锁池、容量、在途、限制池、到期、已在池或不在池等业务失败保留为 `failReasons` 提示，允许可识别的组合及同组配套项提交
- 凭证、标的、关联证券或目标池无法识别、类型错误、权限不足、主体选择不合法及 ABS 身份冲突仍阻断；关联主档缺失阻断整个来源组
- Excel 主项保留完整单笔候选，再追加目标池已配置的 batchIn/batchOut 并推荐；未配置时保留单笔推荐，不生成额外的批量无需审批候选
- Excel 提交不再因近期重复业务申请、在途、配套互斥调出可行性、报告必填或组合在池状态重新阻断；导入批次仍禁止重复提交，已提供的报告引用仍须有效
- 直通预检和人工终审通过同组 Excel 主项批次识别配套项，采用相同提示放行口径；标的、CRMW 凭证及目标池必须存在，ABS 身份仍强制检查
- Excel 重复调入先软删除同凭证、实际标的、目标池的旧有效状态再写新状态；调出已不在池时按完成处理，不影响其他凭证组合
- 提交保留实际选择的流程 ID、Key、类型，成功响应回显本次选择，批次校验快照仍保留校验时的流程。单笔和批量共用同一流程定义时，页面按所选流程类型回显。只有审批通过或直通成功才落池，整批数据库异常仍回滚
- Excel 提交使用本次已加载并核实的证券信息逐日志保存申请快照，非 ABS 也保存；不重复查询主档、不写回主档，审核和历史详情按申请快照回显
- 保留原候选来源、模板和页面操作，不新增表结构
