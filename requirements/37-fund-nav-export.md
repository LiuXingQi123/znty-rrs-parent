# 基金净值导出需求说明

> 前端页面：`fund_nav_export.html`  
> 后端前缀：`/api/v1/fundNavExport`

## 1. 功能范围

按基金基础信息查询证券名称、证券代码和市场。用户勾选一个或多个基金后，选择净值日期范围并下载 Excel。导出文件为每只基金一个工作表，工作表 A 列为净值日期，B 列为基金单位净值。

基金信息主表为 `rrs_fundinfo`，仅查询未逻辑删除记录；逐日净值来自 `rrs_fund_nav`，按 `fund_code` 关联并只导出未逻辑删除的净值记录。

## 2. 查询条件

| 条件 | 请求字段 | 说明 |
|---|---|---|
| 证券名称 | `fundName` | 模糊匹配基金全称或简称 |
| 证券代码 | `fundCode` | 模糊匹配 |
| 市场 | `marketCodes` | 市场编码多选，显示名称由前端市场字典映射 |
| 当前页码 | `pageIndex` | 从 1 开始 |
| 每页条数 | `pageSize` | 遵循公共分页限制 |

## 3. 表格与导出

表格字段：证券名称、证券代码、市场，并提供多选列。分页切换时保留勾选；执行新查询或重置条件时清除勾选。

点击“导出净值”后先弹出日期范围选择框。日期范围两端均包含，必填。导出只包含勾选的基金，不受表格当前页限制。每只所选基金生成一个以证券名称命名的工作表，首行为“日期 / 基金净值”，之后每个交易日期占一行：A 列日期按 `yyyyMMdd` 写入，B 列为单位净值数值。若名称重复或超过 Excel 工作表名称限制，则追加基金代码以生成合法且唯一的工作表名。所选基金在日期范围内没有净值记录时，仍生成带表头的空工作表。

## 4. 接口清单

| 路径 | 用途 |
|---|---|
| `POST /api/v1/fundNavExport/queryFundNavFundPage` | 按名称、代码、市场分页查询未删除基金信息 |
| `POST /api/v1/fundNavExport/exportFundNavExcel` | 按所选基金代码和净值日期范围生成多工作表 Excel |

导出请求字段：`fundCodes`、`navDateStart`、`navDateEnd`。日期参数格式为 `yyyy-MM-dd`。每只基金与日期范围之间按 `rrs_fund_nav.fund_code`、`trade_date` 查询，净值字段为 `unit_nav`。

## 5. 验收标准

- 名称和代码支持模糊搜索，市场支持多选筛选，列表只显示未逻辑删除的基金。
- 用户可以勾选跨页基金；未勾选基金不得出现在导出文件中。
- 导出按钮先要求选择有效的开始和结束日期，开始日期不得晚于结束日期。
- 每只所选基金有独立工作表，净值记录按日期升序排列，日期格式为 `yyyyMMdd`。
- 同一基金同一天出现多条有效净值记录时，导出失败并明确提示数据冲突。
