# 30 恒生格式手动导出

## 证券身份与市场代码（当前接口契约）

- `rrs_securityinfo.isin_code` 为非空主键；正式券使用真实 ISIN，临时券使用 `TEMP:临时代码`。不再提供 `wind_code` 总码，也不增加 `security_ref_type`。
- 调库、池状态、收藏、报告、提醒及批量缓存按 `isinCode` 识别整券；同券同池只占一份容量，同券不同市场码不能绕过已在池和在途检查。主体、独立基金、股票继续使用原业务代码。
- 证券代码搜索传 `securityKeyword`，后端在括号内对 `wind_code_sh`、`wind_code_sz`、`wind_code_nib`、`wind_code_bj`、`wind_code_nbc` 做 OR 模糊筛选。任一市场符合目标池配置即可整券入池，全部有值代码同步生效、同步出池；仅审批通过 `20` 落池。
- 页面“证券代码”保留一列，通过各页面 `new Vue` 内的方法与 Element UI 插槽按沪、深、银行间、北、其他顺序换行展示全部有值代码，仅显示代码本身、不加市场名前缀；空值不占位，长码可折行；可点击代码与证券简称使用相同链接样式，普通代码继承表格文字样式。点击任一码打开同一 ISIN；临时券明确标示临时来源。无公共证券代码脚本或自定义组件。
- CRMW 凭证只使用银行间编码。`crmwIsinCode` 标识凭证、`isinCode` 标识标的，两者与目标池组成业务组合；`crmwScode` / `crmw_scode` 只作银行间代码快照，不作身份。
- POST 路径及响应包装不变。旧代码身份请求明确失败；旧 URL、导入校验草稿须重新选择或重新上传。不能使用状态行 `id` 代替证券身份；日志 ID、附件 ID 仍各有其用途。
- 通用证券 Excel 导出分别提供 ISIN 与五码列；历史及打印读取业务快照。恒生按实际市场码展开，增量删除沿用原入池事件代码，不能输出 ISIN 或临时代码作为正式银行间代码。


## 页面位置

- 菜单：研究管理 → 债券研究 → 恒生格式手动导出。
- 位于“临时代码管理”之后。
- 前端页面：`pages/hs_pool_manual_export.html`。

## 导出条件

| 字段 | 必填 | 说明 |
|---|---|---|
| 投资池 | 否 | 使用投资池树多选，树默认收起，仅可选择叶子池；未选择时导出全部叶子池 |
| 开始时间 | 是 | 精确到秒，格式 `yyyy-MM-dd HH:mm:ss`；增量模式作为时间窗口下界 |
| 结束时间 | 否 | 精确到秒；未填写时使用点击导出时的服务器当前时间 |
| 导出模式 | 是 | `increment`=增量，`full`=全量 |

结束时间不得早于开始时间。全量模式为保持页面条件统一仍要求开始时间，但数据范围以当前在池状态为准，不按时间过滤。

## 导出逻辑

- 全量模式复用 `HsPoolFullExcelExportService`：导出当前已生效的非主体证券和 CRMW；普通证券排除已到期数据，CRMW 不校验到期日。
- 增量模式复用 `HsPoolIncrementExcelExportService` 的查询和工作簿格式，直接使用页面时间窗口 `(开始时间, 结束时间]`，不读取定时任务水位线、不修改业务调库日志。
- Sheet、表头、恒生市场编码、市场拆行、同名 Sheet 合并等规则与恒生池定时任务一致；市场名称列当前字段映射为沪市 `1`、深市 `2`、银行间 `4`、北交所 `6`、其他市场 `99999`，完整编码集中维护在 `HsMarketCode`；证券代码去掉首个 `.` 及其后的市场后缀。
- 页面下载直接返回 Base64 `.xlsx`，不写服务器导出目录、不生成备份、不上传 FTP。

## 接口

`POST /api/v1/hsPoolManualExport/exportHsPoolExcel`

请求示例：

```json
{
  "poolIds": [15, 16],
  "startTime": "2026-08-01 00:00:00",
  "endTime": "2026-08-31 23:59:59",
  "exportMode": "increment"
}
```

返回 `CommonFileDto`：文件名、MIME 类型、文件大小和 Base64 文件内容。
